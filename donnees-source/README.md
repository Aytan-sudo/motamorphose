# Sources du dictionnaire

Ce dossier n’est pas versionné. Pour reconstruire les fichiers de jeu, y
placer les ressources suivantes :

- `Lexique400.tsv` — Lexique 4.00, CC BY-SA 4.0,
  <https://lexique.org/databases/Lexique400/Lexique400.tsv> ;
- `commonNoun_Morphalou3.1_CSV.csv`,
  `adjective_Morphalou3.1_CSV.csv` et `verb_Morphalou3.1_CSV.csv` — extraits
  de Morphalou 3.1, LGPL-LR,
  <https://hdl.handle.net/11403/morphalou/v3.1> ;
- `lexique-grammalecte-fr-v7.7.txt` — Grammalecte 7.7, MPL 2.0,
  <https://www.grammalecte.net/dic/lexique-grammalecte-fr-v7.7.zip>.

Le script conserve les noms, adjectifs et verbes à l’infinitif. Une forme est
acceptée lorsqu’elle est confirmée par deux sources, ou lorsqu’elle satisfait
les seuils de familiarité de Lexique. Seule une sélection à très haute
prévalence devient « commune » et peut servir aux solutions proposées.
